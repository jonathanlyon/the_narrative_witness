# The Narrative Witness: Founder Foundation Pack

This repository is the evidence base and founder-review workspace for the next
build of The Narrative Witness. It is not the application.

The governing promise is:

> Somewhere to write.  
> Someone to hear.  
> Something to hold.

The pack begins at [`docs/foundation/00-executive-brief.md`](docs/foundation/00-executive-brief.md).
Its companion review experience is a self-contained local site in
[`founder-pack-site`](founder-pack-site/README.md).

## Boundaries

- The new founder brief is the sole authority for product direction.
- The earlier `narrative-witness-studio` repository is read-only evidence.
- `tnw_mvp_studio/` is a separate, empty application repository and is ignored
  here. Nothing in the foundation-pack work modifies it.
- This repository contains no production credentials, private writer material,
  deployment configuration, or application implementation.

## Read the pack

Open [`founder-pack-site/dist/index.html`](founder-pack-site/dist/index.html) in
a browser after the site has been built, or run the local server described in
the site README for the complete interactive experience.

## Evidence language

The documents distinguish:

- **Observed:** directly inspected in a repository or live public surface.
- **Documented:** asserted by an earlier internal record but not independently
  reverified.
- **External evidence:** supported by a cited public source.
- **Founder decision:** explicitly decided in the new brief or review.
- **Hypothesis:** plausible and testable, but not yet validated with writers.
- **Recommendation:** a proposed decision based on the available evidence.
